# ryxnontop

Made by Ryan J.

Windows and macOS downloads and release notes. Each user supplies their own API keys.

## Download and install

Open [Releases](https://github.com/ryancpjay-ux/ryxnontop/releases) and choose your platform under **Assets**. The Source code archives are not the application.

### Mac — 0.20.1, Apple Silicon

Download **ryxnontop-0.20.1-macOS-Apple-Silicon.zip**, extract it, and copy **ryxnontop.app** to Applications. This is the exact installed Mac version currently used by Ryan, packaged without rebuilding or applying the Windows-only changes.

This build supports Apple Silicon (M-series) Macs, not Intel Macs. It is locally signed but not Apple Developer ID signed or notarized, so other Macs may block it. Trusted distribution requires Developer ID signing and notarization. Another Mac has not been runtime-tested.

### Windows — beta 0.20.2, x64

Download **ryxnontop-0.20.2-Windows-Setup.exe**, run the installer, then launch **ryxnontop** from your desktop or Start menu. This installer is unsigned. Automated regression tests and package checks passed on macOS; live Windows installation, capture, and authentication still need real-world testing.

## First-time setup

- In **Settings > AI & keys**, choose your provider and add your own API key. Use **Test API Connection** to check it.
- In **Settings > Listen**, add your own Deepgram API key.
- Allow microphone or screen capture when prompted. If capture is blocked, open **Permissions** in the app for checks and operating-system settings links.
- Each user supplies their own keys and API billing. No saved API keys or personal workspace data are included in downloads.
