# ryxnontop

Made by Ryan J.

Windows beta downloads and release notes. Download the installer from Releases. Each user supplies their own API keys.

## Download and install

1. Open [Releases](https://github.com/ryancpjay-ux/ryxnontop/releases).
2. Open the newest Windows beta release.
3. Under **Assets**, download the file ending in **Windows-Setup.exe**. Do not download the Source code ZIP.
4. Run the installer, then launch **ryxnontop** from your desktop or Start menu.

## First-time setup

- In **Settings > AI & keys**, choose your provider and add your own API key. Use **Test API Connection** to check it.
- In **Settings > Listen**, add your own Deepgram API key.
- Allow microphone or screen capture when prompted. If capture is blocked, open **Permissions** in the app for checks and Windows settings links.
- Each user supplies their own keys and API billing. No API keys are included in downloads.

## Beta status

The Windows installer is unsigned. Automated regression tests and package integrity checks passed on macOS; live Windows installation, capture, and provider authentication still need real-world testing.
